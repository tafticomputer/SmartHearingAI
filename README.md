# سمعک هوشمند (Smart Hearing AI)

اپ اندروید فارسی (راست‌به‌چپ) برای بهبود کیفیت صدا: میکروفون گوشی ← پردازش ← هدفون/سمعک بلوتوثی.

## امکانات نسخه ۰.۲
- دریافت صدای محیط با میکروفون
- کنترل نویز (حذف خش‌خش)، تقویت گفتار، حذف صدای باد
- تنظیم بم و زیر، کنترل بلندی خروجی
- نمایش وضعیت، سطح ورودی/خروجی و تأخیر تقریبی
- اجرا به‌صورت سرویس پیش‌زمینه (با خاموش شدن صفحه هم کار می‌کند)

## ساخت APK با گیت‌هاب
1. این پوشه را به یک مخزن (Repository) جدید در GitHub آپلود کنید.
2. به تب **Actions** بروید؛ ساخت به‌صورت خودکار شروع می‌شود (یا Run workflow بزنید).
3. پس از پایان، فایل APK را از بخش **Artifacts** دانلود و روی گوشی نصب کنید.

## نکته‌های مهم
- حتماً با هدفون یا سمعک بلوتوثی تست کنید؛ با بلندگوی گوشی صدا سوت می‌کشد.
- حذف نویز با شبکهٔ عصبی RNNoise (کد C داخل `app/src/main/cpp/rnnoise`، مجوز BSD) انجام می‌شود و با CMake/NDK در گیت‌هاب ساخته می‌شود. اگر کتابخانه بارگذاری نشود، برنامه به حالت ساده (گیت نویز) برمی‌گردد.
- تأخیر با بلوتوث کلاسیک معمولاً ۱۵۰ تا ۳۰۰ میلی‌ثانیه است و ممکن است آزاردهنده باشد؛ هدفون‌های بلوتوث کم‌تأخیر (LE Audio) یا هدفون سیمی بهتر هستند.
- هر سمعک اجازه دریافت مستقیم صدای اپ را نمی‌دهد؛ سازگاری باید آزمایش شود. این اپ جایگزین تنظیم تخصصی سمعک نیست.
